TaxiCheck

Политика конфиденциальности

Дата обновления: 16 ноября 2026 года

TaxiCheck предназначен для учёта смен, доходов, расходов и формирования финансовых отчётов водителя такси. Эта страница описывает публичный демонстрационный сайт, а также обработку данных в отдельной рабочей версии при подключении Google.

Важно: открытый макет TaxiCheck использует вымышленные суммы. Он не запрашивает Google OAuth, не читает Gmail и не подключается к рабочим финансовым источникам.

1. Какие данные используются

В демонстрационном интерфейсе доступны только тестовые записи. Некоторые настройки макета и отметки проверки интерфейса могут сохраняться локально в браузере (например, в localStorage). Пользователь не должен вводить в макет реальные финансовые или персональные сведения.

В отдельной рабочей версии TaxiCheck, после явного подключения соответствующего источника, могут обрабатываться данные о сменах, денежных операциях, расходах и подтверждающих чеках. Конкретный доступ определяется разрешениями, которые пользователь предоставляет при подключении.

2. Доступ к Google и Gmail

Для автоматического поиска чеков в электронной почте рабочая версия запрашивает разрешение https://www.googleapis.com/auth/gmail.readonly. Это разрешение технически позволяет читать сообщения и настройки Gmail, поэтому его объём шире, чем отдельные письма с чеками. Назначение использования в TaxiCheck ограничено поиском и обработкой сообщений, относящихся к подтверждению расходов.

  • Обрабатываются сведения о покупке, такие как дата и время, сумма, категория, продавец и идентификаторы подтверждающих писем, когда они необходимы для учёта и предотвращения дублей.
  • Время покупки, а не поступления письма, используется для определения смены; операции вне смены могут ожидать ручного распределения.
  • Разрешение на чтение не даёт TaxiCheck права отправлять письма, изменять их или удалять через Gmail API.
  • Доступ к Gmail нужен только для функции учёта чеков. Публичный макет работает без него.

3. Для чего используются данные

Полученные сведения используются для финансового учёта, классификации расходов, сверки операций и отображения отчётов пользователю. Данные Gmail не продаются, не используются для рекламного таргетинга и не передаются рекламодателям.

4. Хранение и передача

Рабочая версия использует сервисы Google, включая Google Apps Script и Google Sheets, для обработки и хранения учётных данных. Разрешения OAuth применяются на стороне соответствующего серверного компонента, а не публикуются в исходном коде открытого макета. Публичный GitHub Pages не должен получать содержимое почты, OAuth-токены или реальные финансовые данные.

Передача информации сервисам Google производится в объёме, необходимом для работы выбранных функций. Доступ к данным ограничивается разрешениями и настройками соответствующих аккаунтов. Срок хранения записей зависит от настроек и действий пользователя в рабочей системе; для удаления данных может потребоваться удалить соответствующие записи в хранилище рабочей версии.

5. Отзыв разрешений и удаление данных

Доступ TaxiCheck к Google можно отозвать в настройках подключений аккаунта Google. Отзыв останавливает дальнейший доступ через отозванное разрешение, но сам по себе не удаляет ранее сохранённые учётные записи и финансовые операции. По вопросам доступа или удаления данных можно связаться с разработчиком по контактам, указанным на экране согласия Google.

6. Сторонние сервисы

Демонстрационный сайт размещён на GitHub Pages, который может обрабатывать стандартные технические данные запросов согласно собственным правилам. Для работы отдельной версии TaxiCheck используются сервисы Google, обработка данных которыми регулируется также применимыми условиями Google.

7. Изменения политики

Политика может изменяться при развитии TaxiCheck, в частности перед подключением новых источников данных. Существенные изменения способов обработки Google-данных должны быть отражены здесь до их внедрения. Актуальная версия всегда доступна по этой странице.

8. Контакты

Разработчик проекта TaxiCheck: Kizer-GPT. Общие вопросы и сообщения об ошибках можно оставить в GitHub Issues; не публикуйте там персональные данные, письма, токены или финансовые сведения. Для конфиденциальных обращений используйте контактный адрес разработчика, указанный в Google OAuth.
