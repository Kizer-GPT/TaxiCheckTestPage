# TaxiCheck: автоматическая самопроверка на телефоне (макет)

**Статус:** расширенная самопроверка публичного макета на вымышленных данных. Нет подключений к финансовым API.

## Запуск

После публикации этого PR в **публичном** GitHub Pages откройте:

https://kizer-gpt.github.io/TaxiCheckTestPage/?qa=run

Самопроверка запускается при загрузке. Нажимать по плиткам вручную не нужно. Будет виден список PASS/FAIL и итог.

- **iPhone:** откройте ссылку в Safari. В «Командах» создайте команду: действие «URL» (укажите адрес выше), затем «Открыть URL». Добавьте команду на главный экран или в виджет. Отдельная команда для выполнения JavaScript не нужна.
- **Android:** откройте ссылку в Chrome и выберите «Добавить на главный экран» или «Создать ярлык». Формулировка зависит от браузера. Сам тест работает в странице.

Можно использовать на обоих устройствах просто ссылку, без создания ярлыков.

## Что тестируется

- Загрузка макета и явная маркировка демонстрационных данных.
- Главные суммы и неизменность их отображения после переходов по экранам.
- Наличие 8 плиток отчёта и открытие каждой из них.
- Переключение «Смены» / «Свой период», наличие ночных смен.
- Экраны аналитики, чистого заработка, настроек, демонстрационных подключений.
- Горизонтальный выход за пределы экрана, размер управляющих элементов и обнаруженные JavaScript-ошибки.
- Неверные даты и суммы, переходы между режимами, блокировка демонстрационной авторизации.
- **Синтетические финансовые сценарии:** создание, редактирование, удаление наличных заказов, заправок и прочих расходов; контроль пересчёта кассы, комиссий, аренды, бонусов, чистого заработка и возврат к исходным суммам.

Результат можно скопировать или вручную отправить через системное «Поделиться». Отчёт содержит только названия проверок, статусы, класс устройства и размер браузерного окна. Финансовые суммы, токены и данные аккаунтов не включаются. Автоматической отправки нет.

## Ограничения

**Важное разграничение:** программа проверяет сохранение, редактирование и удаление только **в отдельной временной iframe-копии публичного макета**. Копия загружается самостоятельно, и после проверки уничтожается со всеми вымышленными операциями. В обычной вкладке тестировщика ничего не сохраняется; основные цифры и локальные пользовательские записи не меняются. 

Синхронизация, реальный вход и настоящие финансовые системы не вызываются. В отличие от базовой версии, во временном макете проверяется работа кнопок «Сохранить» и «Удалить», но только на созданных тестом искусственных записях. Скрипт не отправляет никаких результатов автоматически.

Проверка в настоящем Safari/Chrome помогает обнаружить ошибки JavaScript и отображения, но программные `.click()` **не равны физическим касаниям**. Тактильное удобство, работа клавиатуры, масштабирование, прокрутка, реальные сервисы и корректность финансовых начислений проверяются отдельно.

До успешного теста макета **не переносить** эту систему в изолированный Apps Script. Существующий production и тестовая финансовая таблица не изменяются.

## Дополнительная проверка на GitHub

При изменении сценариев в pull request запускается CI с Chromium и WebKit (ширина 375 и 402 CSS px), проверкой повторного запуска, запретом HTTP POST, сохранением текстовых JSON-результатов и скриншотов синтетической проверки. Скриншоты браузерных эмуляций не равнозначны ручной проверке на физическом телефоне.
