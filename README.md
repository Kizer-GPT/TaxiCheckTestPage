# TaxiCheck Test Page

Публичный интерактивный прототип TaxiCheck. Это исключительно демонстрационная страница с вымышленными суммами и примерами записей.

- `index.html` — самостоятельный HTML/CSS/JavaScript интерфейс, без серверной части.
- Никаких обращений к Апарк, Яндекс Про, Google Sheets и другим финансовым API.
- Изменения в демонстрационных формах не записываются в рабочие системы и не отправляются на сервер.
- Не вводите реальные финансовые или персональные данные: репозиторий публичный, а интерфейс предназначен для тестирования.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем **Save**.

После включения Pages сайт будет доступен по адресу:

https://kizer-gpt.github.io/TaxiCheckTestPage/

Для публикации обновления достаточно коммита `index.html` в `main`.

Исходный рабочий проект и все финансовые интеграции остаются в отдельном приватном репозитории.
