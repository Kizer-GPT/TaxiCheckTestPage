# TaxiCheck Test Page

Публичный интерактивный прототип TaxiCheck. Это исключительно демонстрационная страница с вымышленными суммами и примерами записей.

- `index.html` — самостоятельный HTML/CSS/JavaScript интерфейс, без серверной части.
- Никаких обращений к Апарк, Яндекс Про, Google Sheets и другим финансовым API.
- Изменения в демонстрационных формах не записываются в рабочие системы и не отправляются на сервер.
- Не вводите реальные финансовые или персональные данные: репозиторий публичный, а интерфейс предназначен для тестирования.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем **Save**.

После включения Pages сайт будет доступен по адресу:

https://kizer-gpt.github.io/TaxiCheckTestPage/

Для публикации обновления достаточно коммита `index.html` в `main`.

Исходный рабочий проект и все финансовые интеграции остаются в отдельном приватном репозитории.

## Автоматическая проверка Playwright

При каждом коммите, меняющем `index.html` в ветке `main`, GitHub Actions запускает мобильную проверку в **этом публичном репозитории**. Проверка бесплатна на стандартном GitHub-hosted runner для публичных репозиториев.

Workflow: [TaxiCheck public demo Playwright QA](https://github.com/Kizer-GPT/TaxiCheckTestPage/actions/workflows/taxicheck-pages-playwright.yml).

Последовательность:

1. Дождаться, пока публичная GitHub Pages страница будет в точности соответствовать `index.html` текущего коммита (SHA-256), чтобы не тестировать старый релиз.
2. Запустить Playwright / Chromium с мобильными размерами 402×874 и 375×812.
3. Проверить минимальный главный экран (касса после комиссий и чистыми), быстрые записи налички/заправки, все восемь плиток на вкладке «Отчёт», навигацию, полуночные смены и демо-статусы подключений. Отдельно проверить неактивные поля логина и пароля в макете формы входа.
4. Сохранить JSON-отчёт и скриншоты в артефакт GitHub Actions на семь дней.

Кроме автоматического запуска, доступна кнопка **Actions → TaxiCheck public demo Playwright QA → Run workflow** для ручной проверки. Изменения `index.html`, скриптов Playwright или его workflow автоматически запускают QA. Изменения только в `README.md` и `IPHONE_QA_RU.md` не требуют повторного QA, если исходный HTML не менялся.

Тесты выполняются только с полностью вымышленными данными, не используют GitHub Secrets и не обращаются к приватному TaxiCheckApp или платным внешним API. Отчёт и скриншоты в публичном репозитории доступны всем.

## Ручное QA на телефоне

Инструкция для вечернего тестирования: [IPHONE_QA_RU.md](IPHONE_QA_RU.md).

В разделе **«Ещё → Вход и подключения»** статусы и переключаемые сценарии исключительно демонстрационные. Поля логина и пароля в раскрывающемся макете входа заблокированы; кнопка «Войти» тоже не работает. Реальных запросов к Яндекс Про, Апарк, Google или Gmail нет.
